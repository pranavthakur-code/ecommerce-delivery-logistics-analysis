# E-Commerce Delivery & Logistics Performance Analysis

## Project Overview
This project analyses the **Brazilian E-Commerce Public Dataset by Olist** to understand order trends, delivery performance, logistics efficiency, payments and customer satisfaction.

The objective is to identify business insights and evaluate delivery performance using data analytics tools.

## Project Objectives
- Analyse order status and customer purchasing trends.
- Evaluate delivery duration and delivery delays.
- Calculate on-time/early delivery and cancellation rates.
- Compare delivery performance across Brazilian states.
- Analyse payment methods and product categories.
- Explore the relationship between delivery performance and customer reviews.

## Dataset
**Brazilian E-Commerce Public Dataset by Olist**

The dataset contains nine tables covering:
- Orders and Customers
- Sellers and Products
- Order Items and Payments
- Reviews and Geolocation
- Product Category Translation

**Dataset Source:** [Olist Dataset on Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

## Key Performance Indicators (KPIs)

| Metric | Result |
|---|---:|
| Total Orders | 99,441 |
| Delivered Orders | 96,478 |
| Cancelled Orders | 625 |
| Cancellation Rate | 0.63% |
| On-Time / Early Delivery Rate | 93.23% |
| Average Delivery Duration | 12.56 days |
| Average Delivery Delay | -11.88 days |

*Delivery KPIs are calculated using eligible delivered orders with both actual and estimated delivery dates. A negative delay indicates early delivery.*

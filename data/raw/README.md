# Raw Dataset

This folder contains information about the original dataset used in our E-Commerce Delivery & Logistics Performance Analysis project.

## Dataset Source

**Dataset Name:** Brazilian E-Commerce Public Dataset by Olist

**Source:** Kaggle

**Dataset Link:** https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Download Instructions

1. Open the Kaggle dataset link.
2. Download the dataset ZIP file.
3. Extract the ZIP file on your local system.
4. Use the original CSV files for analysis.
